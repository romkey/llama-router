Create the first administrator

This router has no dashboard accounts yet, so the dashboard is locked. The first administrator cannot be created from the web.

Set these environment variables and restart llama-router; the account is created at startup:

LLAMA_ROUTER_ADMIN_USERNAME=admin
LLAMA_ROUTER_ADMIN_PASSWORD=a-long-random-password

The password must be at least 8 characters. Once any account exists the variables are ignored, so you can remove them after the first start and manage accounts under Users.
